# Master Phase Checklist

- [ ] 01 Baseline local test and snapshot
- [ ] 02 Repository safety and governance
- [ ] 03 Requirements and content contract
- [ ] 04 Automated tests and CI
- [ ] 05 Content renderer and validation
- [ ] 06 Design system and responsive QA
- [ ] 07 Search, archive, and SEO
- [ ] 08 Accessibility, performance, and resilience
- [ ] 09 CMS decision
- [ ] 10 Sanity Studio foundation
- [ ] 11 Sanity schema and editor experience
- [ ] 12 CMS integration
- [ ] 13 Draft preview and visual editing
- [ ] 14 Media and archive migration
- [ ] 15 Deployment and revalidation
- [ ] 16 Security, privacy, and backups
- [ ] 17 Editor handbook and handoff
- [ ] 18 Final launch acceptance
- [ ] 19 Post-launch maintenance process

## Rule

Do not mark a phase complete until:

- Required automated tests pass
- Required manual checks pass
- Documentation is updated
- Changes are committed
- Changes are pushed
- No stop condition remains
