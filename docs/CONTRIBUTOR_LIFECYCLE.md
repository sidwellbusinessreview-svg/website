# Contributor lifecycle

New Contributors default to active. Active Contributors appear in the default Article and About selectors. Archived Contributors remain valid on existing Articles and About entries but are hidden from new selections. Restoring a Contributor makes them selectable again.

Use **Archive contributor** when a student graduates, leaves staff, or stops writing. Permanent deletion is for duplicate or erroneous records only.

Every Contributor editor shows **Referenced by**, including Articles and About plus whether each reference is published or contains unpublished changes. If Articles reference the Contributor, permanent deletion is blocked and **Archive contributor (recommended)** or **Reassign articles** is offered. Reassignment preserves byline order, removes duplicate references, patches all draft/published variants found at confirmation time, and then rechecks references.
